# ADR 0068: One source for agent docs: generated blocks, the skill file and the wiki page

Status: accepted by the owner on 2026-11-13 (issue 603, decisions in issue 613). Built (issues 616 to 628, 633 to 639). Decision A-1, A-9 of the agent interface.

## Context
Agent docs that are copied by hand drift. The Claude Code skill, the wiki page and the README section must say the same thing as `AGENTS.md`.

## Decision
- `docs/agents/README.md` is the source of the wiki page 'For AI agents' (generated by `scripts/sync_wiki.py`). `docs/agents/skill/SKILL.md` is a tracked skill with a short body pointing at `AGENTS.md`, the MCP command and the recipes, with install steps in `docs/agents/README.md`; `.claude/` stays gitignored.
- `llms.txt` at the root lists `AGENTS.md`, the recipes, the schemas, the client-testing guide and the manual, one line each.
- The README gets a short 'Using it from an AI agent' section (MCP one-liner, `describe workbench --json`, a link to `AGENTS.md`).

## Consequences
- No new content is invented for these pages: they point at what the generated blocks and recipes already say.
